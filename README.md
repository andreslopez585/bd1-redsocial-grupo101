Descripción del caso
El caso plantea la necesidad de diseñar el modelo conceptual de una base de datos para una nueva plataforma dirigida a estudiantes: la Red Social Pascualina.

Actualmente, las plataformas institucionales existentes son demasiado formales y no facilitan la interacción casual, el intercambio de conocimientos entre pares ni la organización espontánea. Para solucionar esto, se requiere estructurar un sistema que permita a la comunidad educativa realizar las siguientes acciones:

Crear perfiles: Destacando áreas de estudio, habilidades e intereses para fomentar la mentoría.

Conectar con compañeros: Seguir a otros estudiantes con intereses similares.

Interactuar en un feed: Publicar actualizaciones, dudas académicas, recursos útiles e incluso memes.

Formar comunidades: Crear o unirse a grupos de estudio, clubes de pasatiempos o equipos para hackatones.

Gestionar eventos: Programar y coordinar talleres, reuniones o actividades sociales.

El objetivo central del reto es aplicar los conceptos de diseño de bases de datos (Modelo Entidad-Relación) para estructurar cómo se almacenará, conectará y gestionará toda esta información de manera eficiente.
